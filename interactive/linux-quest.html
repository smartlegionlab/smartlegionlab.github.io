How to Play
  1. Complete all 18 missions by typing real Linux commands into the terminal.
  2. Start with whoami, pwd, ls, cat README.md, then explore mkdir, cd, touch, echo, grep, chmod, bash and ps.
  3. help lists all commands, hint gives a tip for the current mission (on Hard it costs XP).
  4. Difficulty: Easy ×1, Medium ×1.5, Hard ×2 XP multiplier.
  5. Escalate: sudo su (password: linux), grab the flags, delete the virus and finish with sudo reboot.
  6. On your phone: the terminal works with the on-screen keyboard — tap the line at the bottom, type a command and press Enter. Play in portrait.
  7. Bonus commands: neofetch, cowsay, fortune, cmatrix, snake.
About
Linux Quest
version 1.0.0

Linux Quest is an educational terminal quest with 18 missions built around real Linux commands.

Filesystem: a virtual machine with /home, /etc, /opt, /tmp and /root. Commands like whoami, pwd, ls, cat, mkdir, cd, touch, echo, grep, chmod, bash, ps, sudo, rm and reboot are simulated.

Progression: each completed mission gives XP; ranks go from Newbie to IT-Hero. Difficulty changes the XP multiplier (Easy ×1, Medium ×1.5, Hard ×2).

Goals: follow the README plan, collect the flags, escalate to root, neutralize the virus and reboot. Hints are free on Easy/Medium and cost XP on Hard.

Everything is real: commands are parsed and executed in pure JavaScript inside a browser terminal.
