How to Use
  1. Pick your side: X (first) or O (second).
  2. Click an empty cell - the brain answers once, then the turn returns to you.
  3. Before training the brain plays randomly; after Fast Learn it plays perfectly.
  4. The brain never loses once trained: it blocks forks and always takes the draw at worst.
  5. The right grid in panel 2 shows the network's rating of all 9 moves for the current board.
  6. The bottom-left console logs every move with its top-3 candidates - press Copy to share.
  7. Export / Import saves and loads the trained brain as JSON.
About
Tic-Tac-Toe Brain Neural Network
version 1.5.0

Tic-Tac-Toe Brain Neural Network is a real multilayer perceptron written from scratch in pure JavaScript: 27 inputs (9 cells, each encoded as X / O / empty) -> 48 sigmoid hidden neurons -> 32 sigmoid hidden neurons -> 9 softmax outputs, one per move.

Teacher: every reachable board position (~4,400 non-terminal) is labeled by a minimax solver, and each position learns a uniform distribution over all its optimal moves. Training uses a low learning rate (0.02) with gradient clipping and per-epoch weight clipping for stability.

Result: once trained, the brain responds optimally from any position on either side - you can beat it only by drawing, exactly as in a perfect game of Tic-Tac-Toe.

The bottom-left console logs training diagnostics and every move with its top-3 candidates - copy it to debug any issue.
