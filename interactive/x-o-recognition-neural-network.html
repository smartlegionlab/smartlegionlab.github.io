How to Use
  1. Draw the letter X on the 8×8 grid using your finger or mouse.
  2. Press + This is X - the drawing is saved to the dataset and the grid clears automatically.
  3. Now draw a letter O (a ring near the edges of the cells).
  4. Press + This is O.
  5. Repeat 3–5 times for each letter, varying the size and position. More varied samples = better accuracy.
  6. Press Start Training. Watch the loss graph go down - that is the network learning.
  7. Draw any new X or O - the network instantly shows its guess with a confidence percentage.

Tips:

  • Pause stops training at any moment; press Start again to continue.
  • Reset re-initializes all weights - predictions become random until you train again.
  • Keep the dataset balanced: a similar number of X and O samples.
  • If recognition is poor, add more samples (especially different styles) and keep training.
  • You can keep drawing while training runs - predictions update live.
  • Export / Import saves and loads the trained brain as a JSON file.
About
X / O Shape Recognition Neural Network
version 1.0.0

X / O Shape Recognition Neural Network is a single-file web app containing a real artificial neural network, written from scratch in pure JavaScript - no frameworks, no libraries, no tricks.

Architecture: a multilayer perceptron (MLP) with 64 inputs (one per grid cell), 12 hidden neurons and 2 outputs (X and O). Sigmoid activation, trained by backpropagation with gradient descent - the same fundamental math that powers modern AI, just in miniature: about 800 parameters instead of billions.

Everything you see is real:

  • Neuron brightness = its actual activation value (0 to 1), rendered as translucent pulsing orbs.
  • Line thickness = weight magnitude relative to the strongest current connection, so the pattern visibly reshapes as the net learns; color = sign.
  • The loss graph = the true error, decreasing as the weights update.

Loss scale: the chart auto-scales to the current range, and the curve is smoothed, so every improvement stays visible and readable. MSE ≈ 0 means the network classifies perfectly; ≈ 0.2 or higher means it is still learning.

Scale-aware rendering: on wide screens all 64 inputs and every connection are drawn; on narrow screens every 4th input is drawn (16 of 64) so the graph stays readable.

Simplifications: this is a classic dense network rather than a convolutional one (CNN), which is what real image recognition systems use.

Purpose: an educational demo - to watch, live, how a handful of numbers reorganize themselves until they can recognize your handwriting. Trained brains can be saved and loaded as JSON.
