How to Use
  1. Pick a logic function: XOR, AND, OR, NAND, XNOR - switching resets the network, so you train it again from zero.
  2. Play: flip a / b - the answer is green when right, red when wrong, with a confidence bar.
  3. 🎲 Random / ✔ Test all run quick checks; results flash in the toast.
  4. Press Start Training or Fast Learn → 100%. Training auto-stops at 4/4 correct and the weights freeze, so Random is always right afterwards.
  5. Adjust learning rate (Precise by default) and pick the optimizer (SGD by default, Adam also available). Press Reset or switch function to retrain.
  6. Export saves the trained brain as a JSON file; Import loads one back - share or keep your trained models.

Why XOR is special: a single-layer perceptron cannot learn XOR - the two "on" corners sit diagonally, no straight line splits them. The hidden layer bends the space; watch the decision map reshape as it learns.

About
Boolean-Logic Neural Network
version 1.0.0

Boolean-Logic Neural Network is a real multilayer perceptron (MLP) written from scratch in pure JavaScript, learning classic Boolean logic with full live visualization.

Architecture: 2 inputs → 3 sigmoid hidden neurons → 1 sigmoid output (> 0.5 = true). Trained by stochastic mini-batch optimization - SGD with momentum (0.9) (default) or Adam. Training auto-stops at 4/4 correct, and switching functions resets the network. Trained brains can be saved and loaded as JSON.

Decision map: every pixel feeds continuous (a, b) through the brain and colors it by output - blue = false, red = true. As it trains, the map reshapes into the correct pattern before your eyes.
