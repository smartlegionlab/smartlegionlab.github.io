How to Use
  1. The dataset is generated automatically on load (~2,000 colors across 12 classes).
  2. Move the R, G, B sliders - the network names the color with confidence.
  3. Press Auto-gen to regenerate and Start Training / Fast Learn to train to 100%.
  4. Teach the network yourself: pick a color chip, then press + Save Sample.
  5. Random throws a random color; try colors between classes (teal, lime, navy).
  6. Export / Import saves and loads the trained brain as JSON.
About
RGB Color Name Guesser Neural Network
version 1.1.0

RGB Color Name Guesser Neural Network is a real multilayer perceptron written from scratch in pure JavaScript: 3 inputs (normalized R, G, B) -> 24 sigmoid hidden neurons -> 12 softmax outputs, one per color class.

Loss: cross-entropy with softmax, trained by mini-batch SGD with momentum (default) or Adam. Training stops automatically at ~100%.

The dataset is synthetic: tight clusters around 12 prototype RGB colors, so classes are realistic yet separable enough for a small network to learn them to ~100%.
