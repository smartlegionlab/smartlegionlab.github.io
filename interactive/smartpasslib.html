How to Use
  1. Smart Password: enter a secret phrase (min 12 chars) and a length, press Generate. The same secret and length always give the same password.
  2. Private / Public Key: the label above the output shows which key is displayed, and the pressed button lights up. The private key is regenerated on demand and never stored; the public key can be kept locally.
  3. Random: Strong and Base create one-time cryptographically secure random passwords. The active mode is highlighted.
  4. 2FA Code: creates a short random code (4-100 chars).
  5. Verifier: proves a secret matches a stored public key without exposing it - useful for restoring access.
  6. Press Copy on any result - it turns into a checkmark to confirm the copy, then reverts.
About
SmartPassLib
version -

SmartPassLib is a client-side, zero-storage smart password generator. It derives passwords deterministically from a secret phrase, so the same secret + same length produce identical passwords in JavaScript, C#, Python, Go, Kotlin, Rust and any language with SHA-256.

Decentralized: no central servers, no cloud, no database. Nothing is ever stored or transmitted; passwords are regenerated on demand.

Key derivation: private key uses 15-30 deterministic iterations, public key 45-60. Public keys verify secrets without exposing them (proof of knowledge).

Core principles: zero-storage security, on-demand regeneration, cryptographically secure via Web Crypto API, and deterministic across platforms.
