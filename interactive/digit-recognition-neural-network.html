How to Use
  1. Draw a digit 0–9 on the grid with mouse/finger - strokes are smooth and anti-aliased.
  2. Tap the matching digit below - it lights up as the active label.
  3. Press ✓ Save - a confirmation pops up and the digit's counter grows.
  4. Erase with the Eraser button, the E key, or the right mouse button (hold and drag).
  5. Press Auto-gen to add hand-style samples, then Start Training.
  6. Acc shows % of the dataset answered correctly (live).
  7. Export / Import saves and loads the trained brain as a JSON file.
About
Handwritten-Digit Recognition Neural Network
version 1.0.0

Handwritten-Digit Recognition Neural Network is a real multilayer perceptron written from scratch in JavaScript: 144 inputs (12×12 grayscale grid) → 24 sigmoid hidden neurons → 10 sigmoid outputs, trained by mini-batch SGD with momentum (exact MSE backprop).

Auto-gen renders digits like handwriting: vector strokes with random rotation, scale, shear, offset, bends, wobble (jitter), pen-lift gaps and variable thickness.

Neuron orbs pulse with activation. Line thickness is relative to the strongest connection, so the wiring visibly reshapes as the net learns. The % beside each output is its confidence. Trained brains can be saved and loaded as JSON.
