How to Use

  1. ~750 names (Russian + English) are loaded - press Start Training.
  2. Type in Russian, English or translit: Александра, Анна Сергеевна, Alexander.
  3. Add your own names with + Is Female / + Is Male.
  4. Green loss goes down, blue train acc and orange val acc go up. Resplit reshuffles the 80/20 split.
  5. Keep a name in the input for ~1 sec to record it in the Guess History. Known names get OK/WRONG automatically; for unknown ones you mark them yourself.
  6. Export / Import saves and loads the trained brain as a JSON file.

About

Name Gender Classifier Neural Network
version 1.0.0

Name Gender Classifier Neural Network - a real neural network in pure JavaScript with live visualization; an upgraded port of the Rust project name-gender-nn-rs.

Normalization: every name is transliterated to latin (Cyrillic to Latin), so Russian, English and translit inputs share one 27-letter alphabet.

Features (2,746 sparse inputs): letter positions, reversed positions, first letter, final bigram/trigram, patronymic bigram/trigram, length bucket, vowel/consonant buckets, diminutive markers.

Core: 48 hidden sigmoid neurons to 1 output (>0.5 means female). Mini-batch SGD (batch 16), momentum 0.9, LR 0.1.

Guessing: every tested name lands in the Guess History; correctness is checked against the dataset when known, or marked manually.

Everything is real: brightness = activation, weight color/thickness = sign/magnitude, curves = true dynamics, bar = true probability. Trained brains can be saved and loaded as JSON.
