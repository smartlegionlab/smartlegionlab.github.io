Name Gender Classifier

2,746 → 48 → 1 · gender from RU/EN names

A real neural network written from scratch in pure JavaScript that guesses gender from names written in Russian, English, or transliteration, using sparse features over a normalized 27-letter alphabet.

GitHub License Try it live

name-gender-classifier-neural-network - a standalone application that implements the full training pipeline by hand: forward pass, error backpropagation, weight updates with gradient descent. An upgraded port of the Rust project name-gender-nn-rs.

Every name is transliterated to latin, so Russian, English and translit inputs share one 27-letter alphabet. The input orbs indicate connection strength - the brighter a letter or suffix, the more the network relies on that feature for its answer.

  • Network trained from scratch - plain JavaScript (sigmoid activation, backpropagation, mini-batch SGD, batch 16, momentum 0.9, LR 0.1)
  • Normalization - every name is transliterated to latin (Cyrillic to Latin), so RU / EN / translit share one 27-letter alphabet
  • Sparse features (2,746 inputs) - letter positions, reversed positions, first letter, final bigram/trigram, patronymic bigram/trigram, length bucket, vowel/consonant buckets, diminutive markers
  • ~750 names (Russian + English) load automatically; add your own with + Is Female / + Is Male
  • 80/20 split - Resplit reshuffles the train/validation split; the loss graph shows loss, train acc and orange val acc
  • Guess History - names held in the input for ~1 second are recorded and can be judged right/wrong
  • Live visualization - active input features, hidden neurons, output confidence and the F/M meter
  • Model persistence - export / import the trained brain as a JSON file
  • Responsive layout - 3-column panels on desktop/landscape, single column in portrait

  1. ~750 names (Russian + English) are loaded - press Start Training.
  2. Type in Russian, English or translit: Александра, Анна Сергеевна, Alexander.
  3. Add your own names with + Is Female / + Is Male.
  4. Green loss goes down, blue train acc and orange val acc go up. Resplit reshuffles the 80/20 split.
  5. Keep a name in the input for ~1 sec to record it in the Guess History.
  6. Export / Import saves and loads the trained brain as a JSON file.

2,746 sparse inputs → 48 hidden sigmoid neurons → 1 output (> 0.5 means female). Features: letter positions, reversed positions, first letter, final bigram/trigram, patronymic bigram/trigram, length bucket, vowel/consonant buckets, diminutive markers. Data: built-in Russian and English name lists; the 80/20 split is reshuffled by Resplit.
