From-Scratch Neural Networks

Collection of real multilayer perceptrons (MLPs) implemented from scratch in pure JavaScript.

This repository is the collection hub. Each of the eight demos now lives in its own standalone repository (own releases, issues, docs and live demo), and this page links you to all of them. No frameworks, no external libraries, no runtime dependencies - train and run a neural network entirely in the browser with live visualization.

GitHub License All Live Demos Try Boolean Logic Try Digit Recognition Try X / O Try Name Classifier Try Chiptune Try RGB Color Try Morse Decoder Try Tic-Tac-Toe

from-scratch-neural-networks - a collection of eight independent applications. Each one implements a complete training pipeline by hand: the forward pass, error backpropagation, and weight updates with gradient descent. Everything runs client-side, so no server or build step is required.

Each application is maintained in its own repository and described on its own project page below. All values rendered on screen correspond to the actual state of the network - the demos show, in real time, how a small network reorganizes its weights to solve a specific problem.

Standalone repositories: Boolean Logic · Digits · X / O · Name Gender · Chiptune · RGB Color · Morse · Tic-Tac-Toe

Live demos live under /interactive/; the index of all demonstrations is at interactive.html.

  • Networks trained from scratch - plain JavaScript (sigmoid activation, backpropagation, mini-batch SGD; the Boolean, Chiptune, RGB Color, Morse and Tic-Tac-Toe apps also offer Adam as an optimizer)
  • Interactive input - draw, type, flip values, press a telegraph key, play a board game, and watch predictions update live
  • Live visualization - neurons rendered as pulsing orbs whose brightness reflects activation; synapse lines show weight sign and magnitude; loss graphs and decision maps reflect real training dynamics
  • Policy learning - the Tic-Tac-Toe app (27 → 48 → 32 → 9) learns a perfect policy from every reachable position labeled by a minimax teacher and never loses
  • Multi-head output - the Chiptune app predicts both the next pitch class and a per-bar rhythm groove
  • Audio - a native Web Audio API engine (no samples) for chiptune with WAV recording, and synthesized telegraph key sounds (dit, dah, key click) for the Morse app
  • Debug console - the Tic-Tac-Toe app logs live training diagnostics and every move with its top-3 candidates, with one-click copy
  • Auto-stop at the learning target - the Boolean, RGB Color, Morse and Tic-Tac-Toe apps freeze the weights the moment training reaches the target
  • Model persistence - every app can export its trained weights to a JSON file and import them back
  • Responsive layout - the interfaces adapt for desktop, tablet, and mobile, including touch drawing
  • Built-in Help and About dialogs - in every application

Each of the eight applications is now maintained in its own standalone repository listed in the Applications table above. To run any of them, clone that repository and serve its folder over HTTP:

git clone https://github.com/smartlegionlab/<repo-name>.git
cd <repo-name>
python -m http.server 8000

then open http://localhost:8000. Each app is split into an HTML file, a stylesheet (css/) and a script (js/), so opening the HTML file directly by double-click will not work - you must serve the folder over HTTP. Any static server works, for example npx serve, or a GitHub Pages deployment.

No build step, no package manager, and no internet connection is required - everything runs 100% client-side once served.
