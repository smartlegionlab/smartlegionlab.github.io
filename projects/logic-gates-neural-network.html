Boolean-Logic Neural Network

2 → 3 → 1 · learns XOR / AND / OR / NAND / XNOR

A real multilayer perceptron written from scratch in pure JavaScript that learns classic Boolean logic live. A good introduction to why a hidden layer is necessary: a single-layer perceptron cannot learn XOR.

GitHub License Try it live

logic-gates-neural-network - a standalone application that implements the full training pipeline by hand: forward pass, error backpropagation, weight updates with gradient descent. It is a good introduction to why a hidden layer is needed - a single-layer perceptron cannot learn XOR, because its two "true" inputs sit diagonally and cannot be separated by a straight line.

The right-hand panel shows a decision map: every pixel of the input space is fed through the network and colored by its output, so you can watch the boundary reshape as the network learns.

  • Network trained from scratch - plain JavaScript (sigmoid activation, backpropagation, mini-batch gradient descent)
  • 2 → 3 → 1 architecture - 2 inputs, 3 sigmoid hidden neurons, 1 sigmoid output (> 0.5 = true)
  • Five gates - XOR, AND, OR, NAND, XNOR; switching a function resets the network so each gate trains from zero
  • Live play - flip a / b (switches, or click the input neurons); the answer turns green when right, red when wrong, with a confidence bar
  • Auto-stop - training stops automatically at 4/4 rows correct and the weights freeze
  • Decision map - every pixel of the input space is fed through the network and colored by its output (blue = false, red = true)
  • Optimizer & learning rate - SGD with momentum (default) or Adam; Med / Fast / Precise
  • Model persistence - export / import the trained brain as a JSON file
  • Responsive layout - 3-column panels on desktop/landscape, single column in portrait

  1. Pick a logic function: XOR, AND, OR, NAND, XNOR - switching resets the network, so you train it again from zero.
  2. Play: flip a / b - the answer is green when right, red when wrong, with a confidence bar.
  3. Random / Test all run quick checks; results flash in the toast.
  4. Press Start Training or Fast Learn → 100%. Training auto-stops at 4/4 correct and the weights freeze.
  5. Adjust learning rate (Precise by default) and pick the optimizer (SGD by default, Adam also available).
  6. Export saves the trained brain as JSON; Import loads one back.

Why XOR is special: a single-layer perceptron cannot learn XOR - the hidden layer bends the space; watch the decision map reshape as it learns.

2 inputs → 3 sigmoid hidden neurons → 1 sigmoid output (> 0.5 = true). Trained by stochastic mini-batch optimization - SGD with momentum (0.9) (default) or Adam; auto-stops at 4/4 correct. The decision map feeds every pixel of the input space through the brain and colors it by output - blue = false, red = true.
