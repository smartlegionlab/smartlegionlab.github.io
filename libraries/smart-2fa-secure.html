Smart 2FA Secure v0.2.4

Advanced Two-Factor Authentication system with enhanced security features

Complex code generation, Telegram integration, flexible TTL, and full test coverage.

Python 2FA Security PyPI Telegram Redis
GitHub PyPI

Advanced Two-Factor Authentication system with enhanced security features.

  • Complex Code Generation — supports ASCII letters, digits and special characters. Customizable code length (default: 6)
  • Flexible Expiration — adjustable TTL (Time-To-Live) for codes. Default 60 seconds expiration
  • Secure Delivery — Telegram integration with customizable message templates

pip install smart-2fa-secure

from smart_2fa_secure import Smart2FA
from smart_2fa_secure.exceptions import InvalidCodeError

smart_2fa = Smart2FA(
    redis_host="localhost",
    redis_port=6379,
    telegram_token="YOUR_BOT_TOKEN",
    code_ttl=60,
    max_attempts=3,
    code_length=6,
)

code = smart_2fa.send_code(user_id="user1", recipient="1234567", message="Your code:")

# Verify with complex code
try:
    smart_2fa.verify_code("user123", "A1b2@#")
    print("Authentication successful!")
except InvalidCodeError:
    print("Invalid security code!")

# Install development dependencies
pip install pytest
pip install pytest-cov

pip install twine

# Run tests with coverage
pytest tests/ -v
pytest tests/ -v --cov=smart_2fa_secure --cov-report=html

# Build and publish
python -m build
